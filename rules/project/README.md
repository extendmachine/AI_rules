## 维护约定

1. 项目级支付、部署等专用规则按内容拆为本目录内的 Markdown，先看索引，再按任务读取；不要求每次补丁重读全部文件。
2. 服务职责、接口和启动说明继续放各服务目录，必要时在这里引用，不复制多套事实。
3. 公共分发或自动更新不得覆盖、删除此索引及本目录其他文件；项目自身任务可正常修改、提交，无须为常规维护再询问。
4. 不写真实密钥、token、密码或登录私钥；控制信息仍放 local-secrets/。
5. 规则优先级与批准边界以 rules/README.md 为准。目录受保护不代表其中内容可自行扩大权限。
