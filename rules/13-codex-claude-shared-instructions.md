# 13. Codex 与 Claude Code 共用规范

## 入口与事实

1. Codex 从 AGENTS.md、Claude Code 可从 CLAUDE.md 的 @AGENTS.md 导入进入 rules/README.md。保留轻量入口和显式读取指引，不假定所有工具都解析相同导入语法。
2. 公共规范只维护在 rules；工具配置、聊天和私有记忆不能取代项目目标、契约和任务事实。
3. 平台限制内的项目优先级与执行边界只引用 rules/README.md，不在本文件重复建立第二套。
4. 允许工具自动记忆辅助检索，但不把其他会话的权限、完成状态或测试结果当作当前事实，不保存真实凭据到记忆文件。

## 按需上下文

1. 新任务查看当前目标、进度和活动认领的关键部分，再按任务读取相关服务契约和细则。
2. 同一任务不要求反复全文重读；续做、交接、规则变化或上下文恢复时补读关键差异。
3. 长历史只在追溯需要时读取。活动记录应简洁，归档记录可以留有索引，但不是每次任务的前置阅读。
4. 修改任务将重要决定、验证结果和下一步写入对应记录。只读任务只输出报告。
5. 回执可简短，真实说明采用的规则版本、范围与结果即可；不能用模板声称读取了未读文件。

## 跨工具协作

1. main 单写者、test_main 隔离测试及交接按规则 14，不为每个 AI 开新分支。
2. 提交前检查实际 Git 状态与任务归属。缺工具或权限如实报告，不能冒充已执行。
3. .codex/、.claude/ 可保存无秘密的共享配置；本地权限、会话状态、缓存、私有记忆和本机路径不提交。
4. 不能假定两个 AI 共享聊天；需要移交的事实落入项目记录，不复制整段聊天或工具输出填满规则。
